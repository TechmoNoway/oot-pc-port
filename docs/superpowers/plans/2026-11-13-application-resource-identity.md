## Bounded design

Use the existing initialized platform's logical process identity as the owned
resource identity. It is not NPDM program ID, Windows PID or an inferred console
value. Both original public accessor entries use one application-only handler,
322, returning full X0 and preserving every other ABI field and the vector bank.
The pure prepare helper and context query counter are transactional. Finalize
disables the query; platform reinitialization retains the process identity and
its context query count. No applet client/session/guest object is fabricated.

The exact original applet export is a B thunk through a relocation-backed PLT
to the 12-byte am getter. The latter is ADRP X8 / LDR X0 / RET. Production audit
checks unchanged original text, complete original symbol census/metadata,
wrapper/PLT/GOT routing, widths/register roles, extents and cache data/BSS bounds.
The application-only am function-export closure has 57 entries in inspected
inputs; both getters are typed providers and all other consumers stay guarded.
Do not change the earlier INIT audit/registry or infer return types from names.
