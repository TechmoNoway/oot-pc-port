## Implementation and retained contracts

1. Run a real-tree RED for the graphics opt-in/context API before promoting the
   exact reviewed prototype. Preserve existing tracked/untracked work. Keep the
   immutable source prototype and all original data/evidence under ignored build.
2. Promote only `native_graphics.c/.h`, context/dispatcher/CLI integration,
   source generation/build changes, provenance/progress tools and their tests.
   Vendor unmodified pinned Khronos API declarations with all original licenses;
   include their headers in source fingerprints and native cache dependencies.
3. Retain ABI2, program flags62/contextAPP512 and every earlier constructor.
   Graphics flags126/contextGRAPHICS1024 require host-linked application startup.
   Reject crossed program/context profiles and preserve all original mandatory
   stages, constructor returns and the actual original nnMain transition.
4. Bootstrap a real Vulkan instance/device/graphics queue transactionally. Ignore
   creation output handles unless the API returned success. Check all counters,
   registers and output separation before effects; unwind partial resources.
   Capture the full working-memory pair, permit the observed `(nullptr, 0)`,
   reuse the device for equal repeats and reject mismatches without effects.
   Preserve all GPR/vector/FP state except the registered PC return. The check is
   void, never a boolean readiness getter. Context teardown owns all resources.
5. Audit original symbol bytes/census and verified text before filtering. Prove
   both boot entry routes, cached full-width pair/state/branch roles, original
   callee PLTs and void precondition behavior. Close all 233 skipped-provider
   exports across GS/GSV/NVSrv/syncpoint/GPU. Preserve the original allocator
   initializer, callback getter and remote-memory query: they execute before the
   replaced boot and must retain their real original constructor/callback work.
6. Preserve the source-bound native crossing proof: verify historical and new
   full traces against native digests, restore the historical first boot STEP
   into the new prefix, match native checkpoint/counters and require an actual
   original caller instruction after return. A native call retires no original
   instruction. Do not require the old resource getter inside the elided parent
   body to run; the old application profile must still reproduce that behavior.
